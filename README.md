# Mohammed Rilwan Portfolio

A professional personal portfolio website for a BSc (Hons) Computer Science graduate focusing on IT Support, Help Desk, and entry-level IT roles.

## Files

- `index.html` — Home page
- `about.html` — About section
- `projects.html` — Project portfolio
- `skills.html` — Skills and technical strengths
- `experience.html` — Academic and career experience overview
- `contact.html` — Contact and inquiry form
- `css/` — Styling and responsive design
- `js/` — Interactions and animations

## How to use

Open the `index.html` file in a browser to view the website.

## Professional features included

- Downloadable CV file for recruiters
- Strong IT support / help desk positioning
- Portfolio sections for projects, skills, and experience
- Responsive design for desktop and mobile devices
- Strong contact and call-to-action sections

## Customization

Update the contact details, social links, and personal information in the HTML files to match your real profile.
